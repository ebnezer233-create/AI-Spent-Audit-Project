## FAQ

**Is this only for startups?**  
No, but it is designed for startup teams that pay for multiple AI tools without a dedicated procurement process.

**Do I need to connect billing?**  
No. The MVP uses manual input so users can get value quickly without sharing private billing access.

**Will the tool always recommend downgrading?**  
No. If spend is already reasonable, the audit says so.

**Why does Credex matter?**  
Some teams are using the right tools but paying retail. Credex can help with discounted AI credits when savings are significant.

**Do I need to enter email first?**  
No. Email is asked only after the audit result is shown.
